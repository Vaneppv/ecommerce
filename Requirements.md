Proyecto: E-commerce

Descripción del proyecto
Desarrolla una aplicación frontend de comercio electrónico utilizando el framework trabajado en
la materia Manejo de Frameworks. La aplicación debe presentar una tienda y permitir que sus
usuarios exploren su contenido mediante una interfaz clara y funcional.
La organización, el diseño y las funcionalidades específicas quedan a criterio de cada
estudiante o equipo. Se espera una solución propia, coherente y adecuada al propósito de la
aplicación.
Requisitos
• El catálogo debe contar con scroll infinito y carga progresiva de imágenes.
• Debe incluir búsqueda de productos y filtros por categoría.
• Cada producto debe tener una vista de detalle.
• El carrito debe permitir agregar y quitar productos, cambiar cantidades y ver el total
actualizado.
• Debe incluir inicio y cierre de sesión.
• Debe incluir un formulario de compra simulado con validación de los datos ingresados.
• El proyecto comprende únicamente el desarrollo frontend. No se debe construir un backend
ni una base de datos propios.
• Puedes apoyarte en servicios o fuentes de datos externas, o en datos locales simulados.
• La aplicación debe poder ejecutarse correctamente para su revisión.
Entrega
• Repositorio con el código fuente.
• README con instrucciones para instalar y ejecutar la aplicación.
• Archivo CONTRIBUTING.md con la arquitectura y estructura del proyecto, las convenciones de
código y las herramientas utilizadas, para facilitar la incorporación de nuevos
colaboradores.
